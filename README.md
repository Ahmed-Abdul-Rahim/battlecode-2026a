# search-data

Data for the plan search on branch feat/plan-search (unpacked by scripts/cloud_setup.sh):

- opponents.tar.gz: sources of the 75 opponents (bots/mimic-*, xpl-*, baseline, lg-v23-fuel), no builds
- opponents-fresh.tar.gz: our league rule bot (_rules) and the 13 refreshed top-10 mimics (2026-10-25)
- mapcache.tar.gz: runs/gpusim/maps (map dumps used for map features)
- search-states.tar.gz: runs/search per-map states (state.pkl, cands.json) and result summaries
- live-pack.bin: the league pack the search's slots were built with
